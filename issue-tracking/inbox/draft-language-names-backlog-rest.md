## Description
In plain words: lane 7 did most of the names list (spelling traditions per family, name length by tradition, the
missing name patterns, language names from another root, land names, dish names, scholars' names from a reconstructed
word). These pieces are left:

- **Item 13, spelling that lags behind speech** (English *knight*, French silent endings). Needs a date when a
  language's spelling froze (a state's founding or the Common's spread), so it waits on polities. Today every book
  spelling follows the current sounds exactly.
- **Scholars' names from a type site** (as *Natufian*, *Clovis*). Needs the settlement names to be stable across the
  family's range; only river and reconstructed-word bases are drawn now.
- **E11 confederation and X6 dynasty names** wait on polity and state data in the run (PW-1561's lane).
- **P6 words**: when a people's name becomes an ordinary word ('a wrecker', from *vandal*), the word is listed under
  the people's names but is not put in the namer's lexicon, so it never shows up in texts or the word list.

**What misleads if never done:** spellings look like perfect phonetic transcriptions for every language, so no
language reads as old or literary; and a P6 word appears on the names page but cannot be found in its own language's
dictionary.
