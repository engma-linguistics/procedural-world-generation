## Description
Owner 2026-10-28: curious about language evolution from actual first principles, even if it rarely runs or never ships. Cheap at deme level (no individuals): each deme holds a lexicon of words as phonetic feature-vector sequences with usage frequencies; per generation (~800 per 20 kyr) run production with coarticulation and noise, perception with realistic confusions (Ohala: listener-driven change), learning biased by frequency and against ambiguity, and mixing between demes weighted by the contact record (PW-981). Can run from a stem's sapiens node (PW-965). Species vocal anatomy sets the articulatory space.
Prior art (toy scale): de Boer 2000 and Oudeyer (vowel and syllable systems emerge from imitation), Wedel / Pierrehumbert exemplar models (regular change, lexical diffusion, mergers resisted under functional load), Kirby iterated learning (compositionality, tiny meaning spaces only).
Known failure: without contrast maintenance (misunderstanding costs) erosion wins and everything collapses to mush; build it in, don't patch it after. Morphology and grammaticalization from first principles are beyond the state of the art: keep grammar on PW-982's drifting typology features.
Validation (all unforced): inventory sizes and segment frequencies PHOIBLE-ish; common emergent changes match Index Diachronica frequencies; the sonority sequencing principle emerges (Wright 2004: sonority as cue recoverability); the comparative-method horizon lands near 6-10 kyr. If these pass, the emergent engine can replace PW-982's change catalogue.
