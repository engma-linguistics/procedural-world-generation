## Description
In plain words: the Technology tab used to be one big grid (every people down the side, every tech across the top, a coloured square for each tech a people knew) with a "Firsts" list under it. The owner's ruling on the mock-ups (2026-10-29) named the views to keep (tree, timeline, map, inventory, one tech's cascade) but did not mention this old grid. The new tab keeps it as a sixth view, "Table", last in the row of view buttons, so nothing the owner had is lost.

Options:
- A. Keep it as the last view (as built). It is the only view that shows every people against every tech at once, and the only place the "Firsts" list per track appears.
- B. Drop it, and move the Firsts list into the Tree view's side panel (each tech already says its first there on hover and click).
- C. Keep only the Firsts list as its own small view.

Lean: A. It costs nothing to keep and is the quickest overview for a game master.
- [ ] owner picks A, B or C
