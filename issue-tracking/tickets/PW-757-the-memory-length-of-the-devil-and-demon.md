## Description
PW-754 option A is built: an `[[exonym]]` row's `efold_kyr` is its own memory (reported as `memory_kyr` on the reputation row; rows without
it unchanged). `seven_meals.toml` gives the devil (horns) and demon (antlers) rows 30 kyr. That number is a guess: the run's substrate
takeovers are 1.5-80 kyr old (median ~12), so 30 kyr keeps most of them as legends and drops the oldest. Options: A (as is); B a longer
memory (100 kyr: every takeover is a legend, "devils" for everything that ever invaded); C a legend floor (once earned, never below x).
Two related observations for the owner:
- the owner's "humans among the cervid folk use an ordinary name" is produced by the `neighbour` valence (rich peaceful contact: own name),
  which beats a long conquest memory only when there is no conquest candidate; where a conquest candidate exists the conquest wins, so a
  people that was ruled by the cervid-kin and lives among them still says "demons". Option D: let rich contact (years and a mixed zone)
  override a feared/despised memory older than a threshold.
- the row table only reads substrate takeovers; authored conquests are the `[[event]]` draft.
Lean: A for now; D is worth a look on the run's actual rows.
