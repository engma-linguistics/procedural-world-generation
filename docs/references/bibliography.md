# Bibliography

One line per paper. A ticket or draft cites a paper as `paper:<Key>` in `refs`, and `board.py check` warns when the key is not here. Keys are `AuthorYear` (add a letter if two collide). Add an entry when you first rely on a paper: key, full citation, what was read (full / abstract / data / not read), and where the repo uses it. Never add a citation from memory; copy it from a doc or a page you read. Local PDFs (gitignored) are indexed in `docs/references/tectonics/README.md`.
