# Docs cleanup, 2026-10-23

Owner asked for stale material under `docs/` to be washed away. `docs/` went from about 75 MB (du) to about 21 MB; `docs/review` from 75 MB to 18.6 MB. About 58 MB of file content (about 530 files) was deleted. Everything is recoverable: base commit `d32f7fa` has all of it (`git show d32f7fa:<path>`, `git ls-tree -r d32f7fa docs/review/<dir>`).

Rule used: a file stays if an open ticket (status not done/wontfix, tickets or inbox), the code/tools/tests, or a kept doc (overview, coordination, README, proposals, base-climate, ice-v2 review/criteria) names it by path; whole-directory references only keep the files named. Everything else in a review dir went. Dangling references to deleted paths in open tickets and kept docs were annotated "(removed; see git d32f7fa)".
