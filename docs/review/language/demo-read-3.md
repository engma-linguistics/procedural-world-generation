# Demo read 3 (grammar C demo, published as version 3, 2026-11-08)

A full read before publishing. Earlier reads' bugs are all fixed or nearly. Left, to fix at the cause (grammar D lane, first item):

- Imperative drops the object's accusative while objects are marked elsewhere, no note (elf 16, blue dragon, halfling, drow).
- Reduplication of vowel-initial stems adds a glide the rule text doesn't mention (i˧-ji˧j‼, i-jiw, u-wuk).
- Storm giant plural 'dog' ŋi˨-nɛ˨-ja˧ʁu˧ vs singular n-a˧ʁu˧ (two stem shapes).
- Trudgill-cause wording vs data: "small, tight-knit" for 32k speakers; "few adult learners" with L2 share 0.40/0.42.
- Weak felt families (elf 'middle' tahe̞/-dahe̞, human 'middle' ilai/ilami-); odd glosses "seals (good)", "shellfish (good)".
- Complexity cards: names end in a dangling comma ("Di-a hobgoblins,") — a region missing.
- "1 families of 3+ words" (plural agreement).
- Kenku antipassive note "the doer takes no ergative" in a language without ergative.
- Copula note vs sentence: drow says clitic but sentence writes a separate word; storm giant says suffix but sentence has a free word; two forms both "after a vowel".
- Human 88 negation: note says preverbal clitic, example has it after the verb.
- Blue dragon: ACC marker stranded at clause end after its object 'what' fronted.
- Dwarf 2 ergative: transitive serial verbs 'take'/'give' subjects lack ERG.
- "Fused" vs "suffix" labels contradict the examples (storm giant 3SG/1SG/1PL/2PL; go.2PL = bare go; kobold 1SG/2SG.POSS; dwarf 2PL; human 88 1PL).
- Storm giant "Word shapes": garbled 2SG stem-vowel sentence contradicting "no marker yet for 2SG"; PST+1SG portmanteau without example.
- Kobold possession note "no marker" but example marks the possessed noun; stem change e→ɛ̠ unexplained.
- Kobold: identical forms with different glosses (1SG.OBJ = 1PL.OBJ; house-LOC = house-1SG.POSS); ablative second form never shown.
- Jargon: "no question gram is tracked", "(no LOC gram)", "(no COM gram)".
- PROG and IPFV both translated "(it) is going".
- Spelling in Words tables vs sentences differ (nème/neme; taarhrrirhtĩrh vs taarhrrirhtinrh).
- Minor: ancestors listed among "closest living relatives"; two lects both "the most spoken (3.4 million)"; Orcs table /i˧ŋ/ vs event line /i˧n/; elf 16 2PL pronoun-like word vs pronoun.
- Not shown on this sample (so unchecked): applicative, reciprocal, voice, infixes, incorporation, focus, concord on demonstratives/verbs — the demo picker could prefer languages that show new features.
