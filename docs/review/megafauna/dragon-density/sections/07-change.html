7. What the model should change

This section takes the literature as the judge. Each item says what is wrong or weak, the evidence and where it is, and which way fixing it would move dragon numbers, and by how much where that can be computed. The order is by how much each matters for the numbers on this page. Each item has a matching draft ticket (Appendix A).
