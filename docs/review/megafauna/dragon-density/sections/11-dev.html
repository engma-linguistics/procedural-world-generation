Reproducing the page

  • Inputs: /home/daniel/personal/repos/procedural-world-generation/data/review-inputs/dragon-r2/ (outside the repo; persistent). run.sh runs jobs.txt (54 jobs, 6 at a time) through job.sh, which exports the model at commit {{ N['runs']['rev'][0] }} and runs docs/review/megafauna/probe.py WORLD ROLL OUT.json --eras 31,29,25,10,0 --cells DIR with --no-press (pressure off) or --no-persecute (persecution off). Each output JSON records the commit (rev).
  • Numbers: PYTHONPATH=. uv run python docs/review/megafauna/dragon-density/dragon_numbers.py DIR docs/review/megafauna/dragon-density/numbers.json (uses sensitivity.py, analytic).
  • Charts: uv run python docs/review/megafauna/dragon-density/charts.py docs/review/megafauna/dragon-density/numbers.json DIR docs/review/megafauna/dragon-density/charts (light and dark copies; charts/boxes.json).
  • Page: uv run python docs/review/megafauna/dragon-density/build_page.py fills every {{ '{{' }} … }} in page.tmpl.html and sections/*.html from numbers.json; no model number on the page is typed by hand.
  • Claims: claims.md lists every cited claim (C1 to C40) with its page and model counterpart; changes-r2.md maps every review point to what was done.
